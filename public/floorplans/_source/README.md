## 図面を修正したときの手順

1. Figmaで直して、同じ範囲をSVGで書き出す
2. このフォルダのファイルを置き換え、`../` にも同じ内容をコピーする
3. **図面のサイズが変わった場合のみ** `src/lib/floorplanRooms.json` の x, y（%）を直す
   - 部屋の中心を、その階の図面の左上を 0%、右下を 100% とした割合で書く

## 色の決めごと

| 対象 | 色 |
|---|---|
| 階段・エレベーター（塗り） | `#A8BCC7` |
| 階段・EVのアイコン | `#1B3140` |
| 「外へ」などの出口表示 | `#F2AB3E` |
| 男子トイレ / 女子トイレ | 既存のまま（青 / ピンク） |

階段を目立たない灰色にしているのは、教室（企画）の待ち時間の色分け（緑・黄・赤）と
張り合わせないため。ただし純グレーだと「使用不可」に見えるので青みを入れている。
